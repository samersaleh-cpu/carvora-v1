# CARVORA V1

CARVORA is a mobile-first vehicle intelligence dashboard built with plain HTML, CSS and JavaScript.

## V1 features
- Vehicle Profile
- Car Health Score
- Maintenance Tracker
- Smart Priorities
- Ownership Cost Calculator
- LocalStorage persistence
- Free calculator landing experience
- Free / Pro product structure ready for expansion
- Responsive mobile-first interface

## Run
Open `index.html` in a browser. No build step or framework is required.

## Deploy
The project is designed for GitHub Pages and other static hosting platforms.

## Data
Vehicle and calculator data are stored locally in the browser using `localStorage`. V1 has no backend and no payment processing; Pro labels are product scaffolding for future releases.
